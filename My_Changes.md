# Changes



##### 11/26/26

1. Left/Right arrow keys move the cursor in the expression, so numbers and functions can be added or deleted anywhere (Backspace deletes before the cursor).
2. The x key is the multiplication shortcut in Simple and Scientific modes (Graphing keeps x as the variable).
3. Scientific mode: holding Shift enables 2nd and holding Ctrl enables Alpha; releasing the key turns the mode off. With 2nd on, s/c/t/l/n/r give the 2nd functions; with Alpha on, letters are typed directly.
4. The Delete key clears the whole expression.
5. Math Notes: x between a number or ")" and the next word-free character becomes a multiplication sign (×).

##### 11/25/26

1. Increased the width size for the basic calculator on the right side while in Scientific mode.
2. Removed the useless pencil mode that "enables" Math Notes (which doesn't do anything).
